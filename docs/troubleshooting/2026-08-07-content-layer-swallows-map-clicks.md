# Home 컨텐츠 레이어가 지도·지역 클릭을 통째로 삼켰다

- 날짜: 2026-08-07
- 관련 이슈키: S15P11A705-376, S15P11A705-377

## 증상

- 지역 뷰에서 색칠된 시·군·구(특히 서울)를 클릭해도 레코드 팝이 전혀 뜨지 않는다.
- 지도 뷰에서 화면 가운데 영역의 지도 드래그·휠 줌·마커 클릭이 되지 않는다.
- 코드상 클릭 핸들러·데이터 배선은 정상이라 단위 테스트로는 재현되지 않았다(jsdom은 레이아웃·히트 테스트를 하지 않는다).

## 원인

확인된 사실 두 가지가 겹쳤다(둘 다 376부터 존재).

1. **컨텐츠 레이어의 투명 사각형이 입력을 가로챘다.** HomePage의 토글·검색창·카드를 감싼 `relative z-10` + `max-w-6xl` 블록은 눈에 보이는 위젯이 없는 여백까지 포함해 사각형 전체가 클릭을 받는다. 배경 레이어(카카오맵·지역 SVG)는 그 아래에 깔려 있어, 화면 가운데 상당 부분에서 지도가 어떤 입력도 받지 못했다. 한반도 SVG에서 **서울이 그려지는 자리가 정확히 그 사각형 아래**였다.
2. **클릭 대상이 물리적으로 너무 작았다.** 전국을 한 화면에 담는 축척에서 서울 중구 도형은 화면상 약 **5.7 × 3.1px**(종로구 6.7×7.1, 강남구 10.4×8.8). 3px 높이 타깃은 마우스로 맞히는 것이 사실상 불가능하다.

## 해결

- 컨텐츠 레이어에 `pointer-events-none`을 주고, 실제 위젯(토글·검색·카드·검색결과)에만 `pointer-events-auto`를 되돌렸다 — 지도 위 UI의 표준 구조.
- 지역 도형은 `pointer-events="none"`으로 내리고, 지역 **중심에 지름 22px의 보이지 않는 클릭 원**을 따로 두었다(작은 도형이 대상 자체면 다시 못 누른다).
- 검증: 컴포넌트 테스트로 "실제 클릭 이벤트 → 장소명 표시"를 고정. 단 원인 1(CSS 층 가려짐)은 jsdom으로 검증 불가라 **수동 확인 절차를 PR에 필수 항목으로 명시**했다.

## 재발 방지

- 지도(또는 전면 배경) 위에 컨텐츠 레이어를 얹을 때는 **레이어 컨테이너 `pointer-events-none` + 위젯별 `auto`**를 기본 구조로 한다.
- SVG 인터랙션 대상은 도형 크기와 무관하게 **최소 22px 히트 영역**을 별도로 깐다.
- "클릭이 안 된다"류 버그는 핸들러보다 먼저 **위 레이어의 히트 박스**를 의심한다. jsdom 테스트가 통과해도 CSS 층 문제는 잡히지 않는다.
