# "무료 폰트"여도 서브셋·WOFF2 변환이 라이선스 위반일 수 있다

- 날짜: 2026-08-07
- 관련 이슈키: Jira 작업

## 증상

폰트 교체 작업(380)에서 사용자가 지정한 손글씨 폰트 두 종이 연달아 반입 불가 판정을 받았다. 상업 이용 무료라 문제없어 보였지만, 우리 파이프라인(fonts-src 원본 → KS 완성형 2350자 서브셋 → TTF→WOFF2 변환 → git 커밋 → 셀프호스팅)이 라이선스 조항에 걸렸다.

## 원인

"무료"와 "변형·재배포 허용"은 별개다. 확인된 원문:

- **교보손글씨 2025 이유빈**: "수정 및 변경(디지털 포맷 변경), 개작, 개명, 재배포, 유료양도, 재판매를 금지합니다." — 서브셋·WOFF2 변환·셀프호스팅 전부 해당. 웹폰트 임베딩 가부도 출처마다 상충(불확실). fsType=8.
- **온글잎 긍정**: 폰트 내부 name ID에 "Modification of this file requires prior written permission from VoyagerX, inc." / 배포처 약관 "어떤 형태로든 임의 수정 및 개작하여 글꼴을 재배포 하는 것은 금지", "배포되는 형태 그대로 사용해야 합니다". 단 **원본 그대로의 재배포·번들·웹 임베딩은 허용**(fsType=0)이라 원본 통짜 서빙(브로틀리 3.47MB)은 합법 — 성능상 채택하지 않았다.
- 반면 **제주 서체 3종(고딕·한라산·명조)**: 공공누리 제1유형 — 변형·재배포·임베딩 전부 허용, 문제없이 반입.

## 해결

- 교보·온글잎 모두 반입 중단(파일을 git에 넣지 않음), 손글씨는 기존 금은보화(나눔 계열, OFL) 유지로 사용자 확정.
- 제주 3종만 서브셋해 교체(#162 머지). LICENSE에 근거 기재.

## 재발 방지

폰트 반입 전 3단계 검증을 표준으로 한다(380에서 확립):
1. **폰트 내부 메타** — name ID 0/13(저작권·라이선스 문구), `fsType`(임베딩 플래그) 확인.
2. **배포처 공식 약관 원문** — "수정/개작/포맷 변경/재배포" 금지 문구를 찾는다. 눈누·폰트비의 라이선스 요약표에서 **OFL 행이 '불가'면 서브셋 파이프라인 불가**로 간주.
3. 걸리면 선택지는 (a) 원본 그대로 서빙(허용 시 — 용량 대가), (b) 서면 허락, (c) OFL/공공누리 대체 폰트뿐이다. **커밋 전에 판정한다** — git에 들어가는 순간 그 자체가 재배포다.

`/pr`의 `git add -A`가 워크트리의 검토 중 폰트 파일을 커밋에 끌어들일 뻔한 사고가 실제로 있었다 — 검토 중 원본은 워크트리 밖(스크래치)에 두고, 폰트 작업 커밋은 경로 명시 스테이징만 쓴다.

→ **conventions.md 반영 필요**: "폰트 반입 시 라이선스 3단계 검증(내부 메타·fsType·배포처 약관) 후 커밋" 규칙 추가 검토.
